# Local Accounts Implementation Plan

**Goal:** Add local registration and login with private task lists while
preserving the existing tasks for the first account.

**Spec:** `docs/superpowers/specs/2026-11-07-login-design.md`

**Files:** `todo/auth.py`, `todo/__init__.py`, `todo/db.py`, `todo/routes.py`,
`templates/auth.html`, `templates/index.html`, `static/app.js`,
`static/styles.css`, `.gitignore`, and `README.md`.

## Task 1: Accounts and migration

- Add users schema and a `user_id` column to existing task databases.
- Create the first account and claim legacy tasks in one SQLite transaction.
- Scope list, create, update, and delete operations to a user ID.
- Save a random local Flask secret outside version control.

## Task 2: Authentication and request protection

- Add registration, login, logout, and session user loading.
- Hash passwords, validate credentials, and return generic login errors.
- Require authentication for the page and JSON task routes.
- Require CSRF tokens for state-changing requests.

## Task 3: Browser interface and documentation

- Build login and registration forms and add account/logout controls.
- Send CSRF tokens with task requests and handle expired sessions.
- Document account setup, first-account migration, and the local secret file.

## Review

- Check that every task query includes the authenticated owner ID.
- Check that foreign task IDs return 404 and unauthorized API requests return
  JSON 401.
- Check that passwords are hashed and the session secret is ignored by Git.
- Keep the app unrun, as previously requested by the user.
